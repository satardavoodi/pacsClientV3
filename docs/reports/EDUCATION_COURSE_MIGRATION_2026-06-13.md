## Source → Education model mapping

Source layout (per course):
`Course-N/course.json` + `Item-M/{item.json, *.IPcryp, Dicom##/<pid>/<studyUID>/SRxx/IN*.DCM, CacheFile/SR*.jpg}`

| Source | Target |
|--------|--------|
| `course.json` | `courses` row (name/description/author/outline/tags/modality/body_regions/level) |
| each `Item-M` | one `slide` (title + notes = description + objectives + keywords + provenance) |
| each DICOM study (`Dicom##`) | one `slide_content` `content_type="dicom"` |
| loose image / pdf / video / audio | `slide_content` `image`/`pdf`/`video`/`audio` |
| `.zip` / office docs / archives | `slide_content` `text` note + preserved file (no native viewer) |
| `.IPcryp` / `.IPdcom` (encrypted) | preserved under `_originals/`; one `text` summary note (undecryptable) |

`content_origin = "migrated_pooyanpacs"`, `is_downloaded = True`, `is_my_course = False`.

## Key engineering decisions

1. **DICOM normalisation (essential for the viewer).** The educational viewer
   (`educational_patient_viewer_widget._resolve_dicom_folder`) only opens a study
   folder whose **series subfolders are numeric** (`name.isdigit()`) and directly
   contain DICOM. PooyanPacs uses `…/<studyUID>/SRxx/IN*.DCM`. The importer
   regroups every instance by its real DICOM `SeriesNumber` into
   `course_<pk>/assets/Item-XX/study_<k>/<series_number>/*.DCM`. This is a
   re-organisation only — **every instance is preserved** (verified 27,297 = 27,297).
2. **Loss-less preservation.** Every non-DICOM source byte (CacheFile previews,
   encrypted `.IPcryp`/`.IPdcom`, `item.json`, the 111 MB `.zip`, loose media) is
   copied under `course_<pk>/assets/Item-XX/_originals/`, mirroring the source
   tree. DICOM is **not** duplicated (avoids doubling 11 GB on a disk-constrained
   machine), so total copied (11.75 GB) equals the source exactly.
3. **Enrichment = DICOM facts + AI-drafted text (flagged).** Source titles were
   placeholders (`Course-3`, `Item-7`) with empty metadata. The importer derives
   factual metadata from DICOM headers (Modality / StudyDescription /
   SeriesDescription / BodyPartExamined) and adds AI-drafted descriptions,
   learning objectives and keywords. All AI-generated courses are marked
   `validation_status="needs_correction"`, `needs_attention=1`, and carry an
   `[AI-generated draft - please review.]` flag. **No specific diagnoses are
   asserted.** Curated per-course text lives in `enrichment_overrides.json`.
4. **PHI:** DICOM kept as-is (per request). Patient identifiers are **never**
   copied into course/slide text — titles use anatomy/modality only.
5. **Pedagogical ordering:** items whose title implies overview/normal/anatomy
   sort before case material; otherwise source order is preserved.

## How to re-run / reuse

```powershell
# Dry-run (no DB writes, no copy) — produces a report:
.\.venv\Scripts\python.exe tools\migration\run_education_import.py --root "<Learn>" --dry-run

# Full migration with curated overrides, deleting empty demo courses:
.\.venv\Scripts\python.exe tools\migration\run_education_import.py `
    --root "<Learn>" --overrides tools\migration\enrichment_overrides.json --delete-demos --yes

# Validate:
.\.venv\Scripts\python.exe tools\migration\validate_education_migration.py
```

Programmatic reuse (future local/cloud/Drive/consultation packages):
```python
from modules.education.course_importer import EducationCourseImporter, ImportConfig
EducationCourseImporter(ImportConfig(overrides=...)).import_learn_root(folder)
# or .import_course_package(one_course_folder)
```

## Invariants / regression guards (for future edits)

- **Importer is additive.** It reuses `course_database` public helpers and never
  changes the schema or the existing `import_*` functions. Keep it that way.
- **DICOM must stay in `study_<k>/<numeric series>/*.dcm`** or the educational
  viewer cannot open it. If you change `_materialise_study`, keep numeric series
  folders.
- **Never drop the `_originals/` preservation** — it is the loss-less guarantee.
- **Idempotency:** re-import is skipped when a course with the same
  `import_source_path` exists (`ImportConfig.skip_if_already_imported`).
- **Tests:** `python -m pytest tests/code/education -q` (run with
  `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1` if the local pytest plugin set stalls).
- **Plugin mirror:** `course_importer.py` is mirrored into
  `builder/plugin package/packages/education/payload/python/...`; after edits run
  `tools/dev/sync_plugin_mirrors.py` then `verify_plugin_mirrors.py`.
