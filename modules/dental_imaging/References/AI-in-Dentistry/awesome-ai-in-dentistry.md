# Awesome AI in Dentistry

Repository: https://github.com/mhson-kyle/awesome-ai-in-dentistry

`Awesome AI in Dentistry` is a curated research and development index for
artificial intelligence in dental imaging and dental clinical workflows. It is
not a production dependency for this workstation module and no external source
code, model, or dataset from the repository is merged into the production
codebase at this stage.

## Why this is useful for Dental Imaging

This repository can be used as a roadmap and reference source when planning
future AI-assisted Dental Imaging features. It collects and points to resources
across research papers, datasets, benchmarks, open-source projects, segmentation
methods, detection and classification methods, CBCT resources, OPG/panoramic
X-ray resources, multimodal dental AI work, standards, and guidelines.

Future development areas that may benefit from this reference include:

- Dental AI detection and classification
- Tooth segmentation
- CBCT segmentation
- OPG / panoramic X-ray segmentation
- Caries detection
- Periapical lesion detection
- Periodontal disease assessment
- Impacted tooth detection
- Dental datasets and benchmarks
- Open-source dental AI tools
- Dental imaging standards and guidelines
- Future structured reporting and AI-assisted reporting features

## Review requirements before integration

Any external dataset, model, paper implementation, or open-source code discovered
through this repository must be reviewed separately before it is considered for
integration into the Dental Imaging module.

Required review areas:

- License compatibility
- Clinical reliability
- Dataset quality and provenance
- Model performance and validation methodology
- Security risks and supply-chain trust
- Integration feasibility
- Compatibility with this workstation's DICOM, PyDICOM, VTK, MPR, and dental
  workflow architecture

This reference should guide research, planning, and prototype evaluation only
until a separate technical and clinical review approves a specific resource.
